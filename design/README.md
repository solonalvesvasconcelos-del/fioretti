# Mockups das telas (Claude Design)

Arquivos-fonte do canvas de design usado para revisar visualmente as 5 telas do sistema (início, login, dashboard, novo chamado, área do motorista), reproduzindo as cores e a tipografia de `css/style.css` e `css/fioretti.css`.

- `Main.dc.html`, `Login.dc.html`, `Dashboard.dc.html`, `NovoChamado.dc.html`, `Motorista.dc.html`: um artboard por tela.
- `canvas.json`: posição de cada artboard no canvas.
- `fioretti-logo.jpeg`, `fioretti-guincho.jpg`: cópias das imagens de `assets/` usadas nos mockups (a segunda é uma versão comprimida da foto original).

Canvas publicado: https://claude.ai/code/artifact/f46c5050-4cb5-44a8-8ca2-db05f975e5ea

Estes arquivos são apenas referência visual/mockup e não são carregados pela aplicação (`index.html`, `login.html` etc. continuam sendo a fonte real das telas).
